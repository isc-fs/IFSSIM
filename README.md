# IFSSIM

**Active development happens on the [`dev`](../../tree/dev) branch.** This `main` branch is reserved for future releases — it's intentionally empty until the first tagged release lands.

## Where to look

- 🔧 Code, docs, and PRs → `dev`
- 📦 Pull requests → open against `dev` (it's now the default branch)
- 🚀 Releases → will be merged into `main` and tagged

## Why

`main` and `dev` have unrelated histories — `dev` was set up as the integration line from scratch, and `main` was kept blank for a clean release line. We haven't released yet, so there's nothing on `main` to see.

Switch to [`dev`](../../tree/dev) to read the actual project.
